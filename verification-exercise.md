# Verification exercise evidence

Before releasing the forum post, verify the following manually on GitHub:

1. Open the live Pages URL in an incognito or signed-out browser window.
2. Open each image in `assets/` and confirm it renders.
3. Open the project repository link and confirm the root README loads.
4. Open the London Housing Notebook and confirm its relative data path is documented.
5. Check that no password, API key, private record, or restricted file is present.
6. Ask a classmate to identify the featured project's purpose, one finding, and one limitation.
7. Apply one improvement and record the resulting commit hash in `forum-submission-draft.md`.
