## Reflection (about 200 words)

This portfolio demonstrates my progress in CISC7204 from basic Python data handling to practical exploratory analysis and visual communication. The project collection includes weather, cars, police stop, COVID-19, and London housing analyses. Together, the notebooks show how I load CSV data, inspect missing values, clean and filter records, calculate grouped summaries, compare categories, and communicate results with readable charts. The selected Suggested Exercise work extends those skills into heatmaps, interactive Bokeh graphics, geospatial maps, and statistical reasoning about distributions, confidence intervals, and hypothesis testing. The London housing analysis is the featured project because it combines date processing, area comparisons, price summaries, crime counts, and multiple visualizations in one reproducible case study. The portfolio also demonstrates responsible sharing: I identify limitations, keep assignments and examination work separate, avoid passwords and private data, and document that dataset licences still need final verification before publication. Next, I will improve the portfolio by recording peer feedback, making one documented revision to the featured project, and adding precise original data-source citations and licence information. I also plan to improve the visual explanations so each chart states the finding it supports and the limits of the comparison.
